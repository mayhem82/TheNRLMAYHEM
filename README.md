# The NRL MAYHEM

Persistent, auditable NRL tipping intelligence.

The repository records fixtures, kickoff-driven audit checkpoints, pre-match evidence, locked MAYHEM tips, confidence, results and post-match signal review.

## Integrity rule

No hindsight contamination. Historical results are not retroactive MAYHEM tips. A genuine pre-match selection is frozen before kickoff and can later be graded, never rewritten.

## Match audit cycle

- T-24h — initial intelligence scan
- T-3h — team availability and market refresh
- T-60m — late mail and final intelligence scan
- T-10m — evidence freeze and MAYHEM tip lock
- Post-match — result grading and signal-performance review

Automation timebase: Australia/Sydney. If an official kickoff changes, future checkpoints are recalculated.

## Evidence flow

Official evidence → statistical evidence → market intelligence → specialist reporting → club/community intelligence → weak signals → corroboration → contradiction analysis → confidence adjustment → MAYHEM tip.

Evidence classifications: VERIFIED, UNVERIFIED, CONTRADICTED, SIGNAL.
